# HexHub

Windows 游戏配置与管理工具。

## 下载

打开[最新版本](https://github.com/takemybear111-cyber/HexHub/releases/latest)，下载 `HexHub-版本号-win-x64.zip` 完整目录包，完整解压后双击 `win-unpacked/Hanbot Studio.exe`。

首次运行不需要开发环境或 GitHub 账号。请保留解压后的全部文件夹；软件数据统一位于 `Hanbot-UserData`。

## 更新

进入“设置 → 软件更新”检查版本，自行选择下载并更新。其他分包与 `current.json` 供软件更新使用。

发布内容包含已编译程序、共享配置及 league of legends 文件夹；项目源码与个人卡密不公开。
