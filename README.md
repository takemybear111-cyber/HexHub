# HexHub

Windows 游戏配置与管理工具。

## 首次安装：只需一个 EXE

[下载 HexHub-Downloader.exe](https://github.com/takemybear111-cyber/HexHub/releases/download/downloader-v1.0.1/HexHub-Downloader.exe)（约 27.5 MB），双击后自动下载最新主程序、league 文件夹和全部配置，校验后安装并启动。无需 GitHub 登录、Python、Node.js，也无需手动解压。

默认安装到 `%LOCALAPPDATA%/Programs/HexHub` 并创建桌面快捷方式。支持续传，已有安装与数据不会覆盖。

配置包含软件偏好、游戏主配置、出装/符文缓存、图库收藏、外观音效、选人记忆、账号文件和游戏卡密。首次启动主程序自动导入。绑定旧 Windows 账号的加密登录信息可能需要重新填写。

## 已安装设备

进入“设置 → 软件更新”检查并选择更新，保留本机路径、已有账号卡密及更新的缓存。游戏主配置由“应用主配置”按钮写入游戏文件。

也可从[最新主程序版本](https://github.com/takemybear111-cyber/HexHub/releases/latest)下载完整 ZIP 目录包作为备用。
