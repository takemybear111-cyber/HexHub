# HexHub

Windows 游戏配置与管理工具。

## 下载

打开[最新版本](https://github.com/takemybear111-cyber/HexHub/releases/latest)，下载 `HexHub-版本号-win-x64.zip`，完整解压后运行 `win-unpacked/Hanbot Studio.exe`。不需要开发环境或 GitHub 登录。

2.0.38 起，完整包及软件更新一并提供软件偏好、当前游戏主配置、出装/符文缓存、图库收藏、外观音效、选人记忆、账号文件和游戏卡密，首次启动自动导入。账号及 API Key 保留原加密格式，换 Windows 账号后可能需要重新填写。

## 更新

进入“设置 → 软件更新”检查并选择更新。已有设备保留自己的账号、卡密、本机路径和更新的缓存。游戏主配置需点击“应用主配置”后写入游戏文件。

发布内容包含已编译程序、配置及 league of legends 文件夹，不含项目源码、GitHub 上传授权或发布签名私钥。软件数据统一位于 `Hanbot-UserData`。
